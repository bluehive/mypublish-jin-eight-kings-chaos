## 2026-11-03 後半初稿の採用表記

| 表記 | 意味と区別 | 根拠 |
|---|---|---|
| 流民 | 戦乱・飢饉などのもとで居住地を離れた人びと。最初から一つの反乱集団ではない | 晋書120 李特載記 |
| 李特／李雄 | 李特は流民の指導者。李雄はその子。両者の活動を一人にまとめない | 晋書120、巻5の李雄記事 |
| 李矩 | 平陽出身の晋系指導者。郷人に塢主へ推される | 晋書63 |
| 五胡 | 匈奴・羯・鮮卑・氐・羌をまとめる歴史叙述上の慣用。統一した政治主体を意味しない | 第5章の分析上の限定 |

| 漢（劉淵の政権）／前趙 | 304年当時の国号は漢。前趙は後世の区別名。改号の細部は次稿で巻103を校合 | 晋書101、巻103は追加確認対象 |
| 懐帝（司馬熾）／愍帝（司馬鄴） | 311年洛陽捕縛は懐帝、316年長安降伏は愍帝 | 晋書5 |
| 司馬睿（元帝） | 317年晋王、318年皇帝。東晋は西晋との区別名 | 晋書6 |

| 建鄴／建康 | 313年の改称を区別。伝記が後の名を用いる場合もある | 晋書5 建興元年八月、巻65 |
| 王導／王敦 | 王導の宮廷での仲介と王敦の軍事的な地位を区別。同族でも一つの意思とはしない | 晋書65・98 |
